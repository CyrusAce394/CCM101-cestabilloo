# Laboratory 10 – Final Mission Reflection
## The Enterprise Cloud Architect

**Subject:** CCM101 – Cloud Computing  
**Project:** CloudNova Enterprise Web Portal

Conducting the activities of Laboratory 10, The Enterprise Cloud Architect, is one of the most important learning experiences that helped me comprehend how cloud computing systems can be created and administered. Working on the last activity, I have learned that the creation of working infrastructure requires not only installing software and running commands but also preparation, configuration, testing, and constant monitoring for the functioning of all the components.

The first lesson I have learned was how a virtual machine can become a fully-fledged server. Using Oracle VirtualBox and Ubuntu Server, we could get acquainted with server management without having additional physical hardware. In addition, I have learned about SSH access that allows managing the Ubuntu Server from Windows Command Prompt and helps learn Linux commands.

One more aspect of this activity is the deployment of our CloudNova Enterprise Web Portal using Docker Compose. Using different containers for WordPress and MySQL, we could see how web applications interact with databases. Thus, I have learned that the organization of services in different containers simplifies the management of the system. We have also used persistent volumes that allow keeping all the important data after restarting the containers.

Finally, security has also improved my skills in this area. Configuring UFW firewall helped to see how network access can be restricted.

I was also educated about automation and data recovery. A Bash script was implemented to backup our database and set the Cron to automate the whole process. Several issues occurred during the process, and patience as well as troubleshooting were needed in order to fix them. Dealing with the issues helped me learn that one needs to understand the error message and check the configuration properly.

The most valuable experience I had in this lab was the success of our system after various testing procedures had been done. The functionality of our WordPress application, storage of data, and database recovery showed how the lessons we had earlier were applied to our project.

Generally, this laboratory helped me learn more about technologies, improve my problem-solving skills, and become a better team player. It made me understand that proper configuration, security, automation, and maintenance are essential parts of a successful cloud infrastructure. The experience motivated me to learn even more since the knowledge I have acquired will help me in my future projects.
