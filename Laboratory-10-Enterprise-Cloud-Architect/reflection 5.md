# Laboratory 10 – Final Mission Reflection
## The Enterprise Cloud Architect

**Subject:** CCM101 – Cloud Computing  
**Project:** CloudNova Enterprise Web Portal

Participating in Laboratory 10, The Enterprise Cloud Architect, was an educational experience that helped me appreciate the practical side of cloud computing. Before completing this activity, I understood some of the technologies individually, but I had limited experience combining them into a complete system. This final project allowed me to see how server management, application deployment, security, and automation contribute to a functional cloud environment.

One of the experiences I found interesting was working with Ubuntu Server through Oracle VirtualBox. We created a virtual server and configured its resources according to our available hardware. I learned that even a simple server environment requires proper preparation and configuration. Using SSH to access Ubuntu through Windows Command Prompt also helped me understand how administrators can manage remote systems without physically interacting with the server.

Another important lesson involved Docker and Docker Compose. By deploying WordPress and MySQL in separate containers, I learned how different application components communicate with one another. I also understood why persistent storage is necessary, especially when applications need to restart or undergo maintenance. Seeing our WordPress information remain accessible after restarting the containers proved that our configuration was working.

The security and automation activities were equally valuable. Configuring the UFW firewall introduced me to the importance of controlling network connections. Meanwhile, creating a Bash backup script and scheduling it through Cron demonstrated how repetitive administrative tasks can be simplified. I realized that automation is useful, but it still requires proper testing to ensure that tasks execute correctly.

What made this laboratory memorable was the troubleshooting process. We experienced errors that required us to review commands, examine configurations, and find solutions. These challenges helped me become more patient and careful when performing technical activities. Successfully verifying our database recovery also gave me confidence that our efforts were producing meaningful results.

Overall, Laboratory 10 strengthened my understanding of cloud infrastructure and encouraged me to become more responsible when handling technical tasks. I learned that successful system administration requires attention to detail, teamwork, communication, and continuous improvement. This experience provided valuable knowledge that I can apply to future projects and my career in information technology.
