# Laboratory 10 – Final Mission Reflection
## The Enterprise Cloud Architect

**Subject:** CCM101 – Cloud Computing  
**Project:** CloudNova Enterprise Web Portal

Laboratory 10, The Enterprise Cloud Architect, allowed me to have an appreciation for the application of cloud computing technologies in practice. In all the laboratory exercises, it has been observed that the construction of a server environment entails planning, knowledge, and collaboration within the group. Unlike other previous laboratories, the third condition is new since it entailed combining a couple of technologies to make them act as a whole.

One of the lessons learned includes the role played by virtualization in helping in creating a server environment without the need for another physical computer. It helped me realize how Oracle VirtualBox and Ubuntu Server can be used to create a server environment. Additionally, the use of SSH has made the task of managing the server much easier due to remote execution of commands through Windows Command Prompt.

Deployment of Docker compose in the laboratory exercise provided me with the chance to see the convenience associated with it. The deployment of WordPress and MySQL as separate containers made me understand the relationship between applications and services. Additionally, it has shown me the significance of using containers in deploying applications due to organization.

Another important lesson that I have learned includes the issue of security and system maintenance. Configuration of the UFW firewall made me understand the importance of controlling the network access. I found out that blocking of unnecessary connections is as crucial as making the application easily available to clients.

Additionally, the backup and recovery activities made me realize the importance of protection of application data. Creation of a Bash script and scheduling of the script through Cron has helped me understand the importance of automation of repetitive processes. The activity was not straightforward due to some mistakes that had to be solved through careful analysis of our commands.

What I liked most about this lab was witnessing how all our hard work culminated in a fully functional WordPress system. Gaining access to the software, validating the stored data, and restoring the data from the database were some accomplishments which made me feel proud of my achievements.

In general, I have become better aware of the concepts of cloud computing and the role of an IT specialist thanks to this lab. It also made me realize that collaboration and constant learning play an important part when undertaking any technological projects.
