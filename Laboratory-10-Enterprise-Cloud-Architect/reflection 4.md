# Laboratory 10 – Final Mission Reflection
## The Enterprise Cloud Architect

**Subject:** CCM101 – Cloud Computing  
**Project:** CloudNova Enterprise Web Portal

Laboratory 10 entitled The Enterprise Cloud Architect gave me insight into the operations of the cloud outside class lessons. It entailed the combination of all learned ideas in order to construct a complete system. The exercise also taught me that cloud architecture requires planning, collaboration, and the ability to learn from errors.

We utilized Oracle Virtual Box in the activity in order to install and set up the server system with Ubuntu. I got to know how virtualization enables one to use a distinct operating system on top of the laptop. Additionally, we set up an SSH connection to be able to manage the server remotely via Windows Command Prompt. The exercise enhanced my understanding of the Linux command line and the importance of remote administration.

Deployment of WordPress and MySQL in the project using Docker Compose was another significant task. I was able to learn how containers can be used to operate various services while connected through the same network. We set up persistent volumes so that important data will still be there once the containers are restarted.

Another interesting thing that I have learned during this lab is about server security. Applying firewall settings using UFW, we have understood how to restrict access to the server and limit incoming connections. In general, it is necessary to remember about the security of the server during the development process.

It was difficult for us to work with the database, its backup and automatic work. We have developed a Bash script for automatic backup and set up Cron for it. Some commands were working incorrectly but it gave us an opportunity to become more attentive and patient. Working with backup of our database, we have found out how important it is to restore all the information that is stored there.

In general, from this laboratory I have developed my technical skills and gained some experience in teamwork. It was useful for me to understand that cloud computing involves not only development of an application but also security, maintenance, automation and protection of the stored information.
